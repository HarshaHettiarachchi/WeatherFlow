# 🌤️ WeatherFlow

WeatherFlow is a modern and responsive weather application that provides real-time weather information and a 5-day weather forecast.

## 🚀 Features

- 🔍 Search weather by city name
- 📍 Get weather using your current location
- 🌡️ Real-time temperature information
- 💧 Humidity information
- 💨 Wind speed information
- 🌅 Sunrise and sunset times
- 📅 5-day weather forecast
- 🌙 Dark mode
- 🔄 Celsius / Fahrenheit temperature toggle
- 🕒 Local date and time
- 🏙️ Recent city searches
- 📱 Fully responsive design
- 🎨 Dynamic weather backgrounds
- 🖼️ Location-based background images

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Open-Meteo Geocoding API
- Wikipedia API
- Font Awesome

## 📸 Application Features

WeatherFlow automatically updates weather information based on the selected city or your current location.

The application also changes its background according to weather conditions such as:

- ☀️ Clear
- ☁️ Cloudy
- 🌧️ Rainy
- ❄️ Snowy
- ⛈️ Stormy

## 📱 Responsive Design

The application is designed to work on:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

The 5-day forecast automatically changes its layout to provide a better experience on smaller screens.

## 🌐 APIs Used

### Open-Meteo Weather API

Provides real-time weather and forecast data.

### Open-Meteo Geocoding API

Converts city names into geographical coordinates.

### Wikipedia API

Used to retrieve location-related images.
